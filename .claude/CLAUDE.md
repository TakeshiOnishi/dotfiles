## 暗号化ファイルの扱い

- `encrypted_` で始まるファイルの変更内容は、次の場所に書かない
    - コミットメッセージ
    - PR のタイトル
    - PR の本文
- 暗号化ファイルを変更したときは、次の定型文を使う
    - コミットメッセージ・PR のタイトル：`chore: <対象> の設定を更新`
        - `<対象>` はファイル名からわかる範囲にとどめる（例：Claude Code）
    - PR の本文：「詳細は記載しない。」
- 暗号化ファイルと平文ファイルの変更は、別のコミットに分ける
    - 平文ファイルのコミットには、通常どおり内容を書いてよい
